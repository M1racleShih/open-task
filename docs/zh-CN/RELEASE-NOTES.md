## 0.1.2-alpha · 2026-10-16

- **“与我相关”筛选：** 组合 **Owned（负责的）、Created or issued（创建或下发的）、Approval or review（审批或验收的）**，跨任务阶段查找自己的工作。同一任务匹配多类关系时只显示一次；取消全部范围则不显示匹配任务。
- 关系筛选与项目、搜索、状态、时间条件共同作用于任务树、甘特图、图谱和团队动态。有权限查看的父任务作为上下文显示，不增加匹配数；待处理事项仍可查看。

此标签按当前登录用户筛选；选择其他成员、记住筛选条件属于上方“未发布”中的后续改进。[对比 0.1.1-alpha](https://github.com/M1racleShih/open-task/compare/v0.1.1-alpha...v0.1.2-alpha)。

## 0.1.1-alpha · 2026-10-16

- **甘特排期：** 工作区默认打开交付排期，同时保留任务图谱。支持总览／日／周／月尺度、今日、选中任务定位、项目分组和可选的前置连线；区分计划周期、仅截止日期、生命周期颜色、逾期和阻塞标记。[使用甘特图](USER-GUIDE.md#查看甘特交付排期)。
- **日历选日期：** 可用日历选择，也可继续手输；日期时间保持 24 小时格式和上海时区含义。
- **进展更易读：** 当前结果与下一步按 Markdown 渲染，支持列表、加粗等格式。
- **清单申请更易填：** 不改变约定范围或验收标准时，原因可选；涉及改变时必填。文本区域更大，并可调整大小，方便编辑较长说明。

[对比 0.1.0-alpha](https://github.com/M1racleShih/open-task/compare/v0.1.0-alpha...v0.1.1-alpha)。

## 0.1.0-alpha · 2026-10-10

首个供开发者本地安装、试用的单团队源码预发布版，包含：

- 创建审批、负责人明确接受、执行与验收人确认完成。
- 经批准的执行清单、正式进展、阻塞协作，以及约定变更后的版本确认。
- 在同一任务中退回和重新提交，保留历次成果与理由。
- 父子、前置和普通关联关系；任务树、图谱、团队动态和按角色呈现的待办。
- 计划日期及个人时间筛选，支持全局和项目设置。
- 英文和简体中文界面及离线文档、浅深主题、OpenTask 猫咪品牌图形。
- PostgreSQL 持久化、可恢复后台任务、迁移、备份及隔离恢复检查。

## 安装与升级

使用 Node.js 24、npm、Docker Engine 和 Compose，按[本地启动](QUICKSTART.md)操作，并同时运行 API 与 worker。源码安装使用 `npm ci`、数据库迁移和生产构建；选择标签可取得对应版本，选择 `mvp` 可体验已合并的开发中改进。保留 `private: true`，OpenTask 以源码分发，不作为 npm 包发布。

已有工作区应先停写并停止 worker，备份并实际验证隔离恢复，再迁移，同时保留旧代码版本。见[发布检查](RELEASE-CHECK.md)。恢复比较覆盖非空时间偏好、会话、幂等记录、worker 心跳，以及业务表和队列任务。

## 范围与已知限制

API 与数据库仅监听本机，会话面向本地 HTTP。公网 HTTPS、反向代理、远程团队访问及生产使用需要另行实现和验证。

非草稿任务对整个团队可见。当前版本不支持通过企业 LDAP 目录登录，也不支持上传附件、向外部发送消息，或接入模型与 AI Agent。证据链接只保存 URL，不备份远程文件。人工体验验收和真实团队长期试用仍待进行。

初始化账号及文档中的密码均用于本地模拟测试，不应把此配置暴露到公网。备份和会话资料属于私有运维数据，不作为发布附件。
