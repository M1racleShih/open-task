# OpenTask 0.1.0-alpha

[English](../en/RELEASE-NOTES.md)

首个供开发者安装、试用的本地单团队任务工作区 alpha 候选。以源码形式分发，计划使用 `v0.1.0-alpha` 标签并标记为预发布。

## 包含内容

- 创建审批、负责人明确接受、执行与验收人确认完成。
- 经批准的执行清单、正式进展、阻塞协作，以及约定变更后的版本确认。
- 在同一任务中退回和重新提交，保留历次成果与理由。
- 父子、前置和普通关联关系；任务树、图谱、团队动态和按角色呈现的待办。
- 计划日期及个人时间筛选，支持全局和项目设置。
- 英文和简体中文界面及离线文档、浅深主题、OpenTask 猫咪品牌图形。
- PostgreSQL 持久化、可恢复后台任务、迁移、备份及隔离恢复检查。

## 安装与升级

使用 Node.js 24、npm、Docker Engine 和 Compose，按[本地启动](QUICKSTART.md)操作，并同时运行 API 与 worker。源码安装使用 `npm ci`、数据库迁移和生产构建。保留 `private: true`，本次不作为 npm 包发布。

已有工作区应先停写并停止 worker，备份并实际验证隔离恢复，再迁移，同时保留旧代码版本。见[发布检查](RELEASE-CHECK.md)。恢复比较覆盖非空时间偏好、会话、幂等记录、worker 心跳，以及业务表和队列任务。

## 范围与已知限制

API 与数据库仅监听本机，会话面向本地 HTTP。公网 HTTPS、反向代理、远程团队访问及生产使用需要另行实现和验证。

非草稿任务对整个团队可见。当前版本不支持通过企业 LDAP 目录登录，也不支持上传附件、向外部发送消息，或接入模型与 AI Agent。证据链接只保存 URL，不备份远程文件。人工体验验收和真实团队长期试用仍待进行，本 alpha 提供可供试用的版本。

初始化账号及文档中的密码均用于本地模拟测试，不应把此配置暴露到公网。备份和会话资料属于私有运维数据，不作为发布附件。
