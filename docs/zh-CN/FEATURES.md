# 功能与操作入口

[English](../en/FEATURES.md)

按你要做的事查操作说明。首次试用先[完成第一条任务](FIRST-TASK.md)，想练习多人流程再读[进阶案例](CASE-CSV-EXPORT.md)。

## 创建与交付

| 功能 | 操作说明 | 阅读 |
| --- | --- | --- |
| 私有草稿与临时任务 | 保存和修改自己的草稿；尚未归入项目的任务可放在临时任务中，草稿可不填日期。 | [查看](USER-GUIDE.md#任务从创建到验收的流程) |
| 删除草稿 | 创建者可以删除自己的未提交草稿；关闭表单不会删除任务。 | [查看](USER-GUIDE.md#任务从创建到验收的流程) |
| 创建审批与退回 | 成员提交任务后，由相应审批人审核；退回后修改并重新提交。 | [查看](USER-GUIDE.md#任务从创建到验收的流程) |
| 直接下发与默认验收人 | 团队负责人可直接下发自己的草稿；验收人按角色与项目规则默认选择，也可显式指定。 | [查看](USER-GUIDE.md#任务从创建到验收的流程) |
| 接收与开始执行 | 负责人可先接收再开始，也可使用“接收并开始”。 | [查看](USER-GUIDE.md#任务从创建到验收的流程) |
| 无法接收与更换负责人 | 负责人说明无法接收的原因；下发人处理，更换后由新负责人重新接收。 | [查看](USER-GUIDE.md#任务从创建到验收的流程) |
| 成果提交与验收 | 负责人提交成果，验收人通过或退回；补充后重交，历次成果与理由保留。 | [查看](USER-GUIDE.md#任务从创建到验收的流程) |
| 改名、取消与后续任务 | 团队负责人可改标题或取消未结束任务；已结束的任务不能重开，后续工作另建关联任务。 | [查看](USER-GUIDE.md#任务从创建到验收的流程) |

## 进展、清单与协助

| 功能 | 操作说明 | 阅读 |
| --- | --- | --- |
| 清单申请、批准与退回 | 负责人提议执行步骤，团队负责人批准后生效，也可退回并说明原因。 | [查看](USER-GUIDE.md#分清执行讨论和正式反馈) |
| 保存清单勾选 | 对照已保存进度与未保存勾选，点“保存勾选进度”或撤销未保存修改；达到 100% 仍需提交成果并通过验收。 | [查看](USER-GUIDE.md#分清执行讨论和正式反馈) |
| 正式进展与评论 | 进展包含当前结果、下一步和下次反馈时间；评论用于讨论，不延后正式反馈期限。 | [查看](USER-GUIDE.md#分清执行讨论和正式反馈) |
| 阻塞与协助 | 写明阻塞原因、所需协助和协助人；协助人回复，负责人解除阻塞。 | [查看](USER-GUIDE.md#分清执行讨论和正式反馈) |
| 申请调整任务要求 | 非团队负责人的参与者可申请调整；团队负责人可以调整约定，也可以只回复并关闭申请。 | [查看](USER-GUIDE.md#修改任务要求并确认新版本) |
| 约定版本确认 | 负责人阅读变更前后的内容并确认当前版本，之后才能提交成果。 | [查看](USER-GUIDE.md#修改任务要求并确认新版本) |
| 清单变更涉及范围或验收标准 | 批准时需设确认期限，并生成新的约定版本，等待负责人确认。 | [查看](USER-GUIDE.md#修改任务要求并确认新版本) |
| 待验收成果被替代 | 待验收时调整约定，会保留原成果并标记为已被替代，任务回到进行中。 | [查看](USER-GUIDE.md#修改任务要求并确认新版本) |

## 任务关系

| 功能 | 操作说明 | 阅读 |
| --- | --- | --- |
| 父子任务与父任务验收 | 每项任务最多一个父任务；子任务完成后，父任务仍需单独提交成果并验收。 | [查看](USER-GUIDE.md#设置任务关系与查看图谱) |
| 前置依赖 | 前置任务须已完成，本任务才能验收通过；仍可提前开始执行。 | [查看](USER-GUIDE.md#设置任务关系与查看图谱) |
| 普通关联与移除关系 | 关联用于记录背景；移除关系不删除任务。父子和依赖不能形成环，具体权限与约束见指南。 | [查看](USER-GUIDE.md#设置任务关系与查看图谱) |

## 搜索、筛选与待办

| 功能 | 操作说明 | 阅读 |
| --- | --- | --- |
| 任务树、甘特图、图谱、详情与链接 | 选中任务查看详情，分区阅读 Markdown 约定并在编辑／预览间切换；复制任务 URL 可以重新打开或分享。 | [查看](USER-GUIDE.md#操作前先读懂这条任务) |
| 甘特交付排期 | 查看计划周期、截止标记与生命周期提示；切换尺度、定位今日或所选任务，并按需显示前置连线。 | [查看](USER-GUIDE.md#查看甘特交付排期) |
| 成员关系筛选 | 选择成员，组合负责、创建／下发、审批／验收关系；条件按账号保存在当前浏览器。 | [查看](USER-GUIDE.md#按成员关系筛选任务) |
| 图谱控制 | 聚焦直接关联、缩放、适应视图、定位选中任务或恢复布局；拖动节点和画布调整视图。 | [查看](USER-GUIDE.md#设置任务关系与查看图谱) |
| 搜索、项目与状态筛选 | 按标题或编号数字搜索，并选择项目和阶段；父任务可显示层级关系，但不计入匹配数。 | [查看](USER-GUIDE.md#搜索任务并按项目状态和时间筛选) |
| 时间筛选与个人设置 | 按周、月或自定义范围筛选；可为项目单独设置，并选择是否显示无日期及此前未完成任务。 | [查看](USER-GUIDE.md#搜索任务并按项目状态和时间筛选) |
| 待处理事项与逾期提醒 | 查看待自己处理的审批、接收、确认、协助、进展或验收；团队负责人还可跟进全队。 | [查看](USER-GUIDE.md#查看待办与操作历史) |
| 任务阶段反馈 | 查看操作结果、变化后的阶段和下一步处理人，通过任务动态核对同事的阶段变更。 | [查看](USER-GUIDE.md#查看待办与操作历史) |
| 任务动态与团队更新 | 查看操作人、时间和字段变化；按作者筛团队更新，并加载更早记录。 | [查看](USER-GUIDE.md#查看待办与操作历史) |
| 面板与手机视图 | 记住面板尺寸和开关，聚焦详情后恢复原布局；手机可切换任务树、工作区和详情页签。 | [查看](USER-GUIDE.md#搜索任务并按项目状态和时间筛选) |

## 项目与账号

| 功能 | 操作说明 | 阅读 |
| --- | --- | --- |
| 项目成员、负责人和颜色 | 团队或项目负责人可维护成员和颜色；只有团队负责人能移交项目管理职责。 | [查看](USER-GUIDE.md#维护项目与账号) |
| 登录、切换与退出 | 演示时可以切换账号体验不同分工；草稿只有创建者可见。 | [查看](USER-GUIDE.md#维护项目与账号) |
| 创建账号与角色 | 管理员创建账号并选择角色；账号角色与每条任务的负责、验收分工不同。 | [查看](USER-GUIDE.md#维护项目与账号) |
| 停用与启用账号 | 停用前移交尚未完成的职责；不能停用团队负责人或自己，启用状态变化会撤销已有会话。 | [查看](USER-GUIDE.md#维护项目与账号) |
| 语言和主题 | 界面支持中英文与明暗主题，选择保存在浏览器；任务正文不会自动翻译。 | [查看](USER-GUIDE.md#切换语言主题和手机视图) |
