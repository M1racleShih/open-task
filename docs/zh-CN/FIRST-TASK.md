# 完成第一条任务

[English](../en/FIRST-TASK.md)

这段练习用一条“整理试用反馈”任务，体验创建、接收、记录进展、提交成果和验收。先完成[本地安装与登录](QUICKSTART.md)，再预留约 10 分钟操作。下面使用三个演示账号；在实际团队中，各人用自己的账号完成相应步骤。

## 1. 创建项目和任务

以 `leader` 登录，点击 **New project（新建项目）**。项目名称填“OpenTask 试用”，项目负责人选 **Test Project Manager**，项目成员选 **Test Member**，提交表单。

点击 **New task（新建任务）**，填写：

| 字段 | 试用内容 |
| --- | --- |
| Title（标题） | 整理试用反馈 |
| Project（项目） | OpenTask 试用 |
| Owner（负责人） | Test Member |
| Reviewer（验收人） | Test Project Manager |
| Expected result（预期结果） | 整理本次试用中顺手和难理解的地方，提交一份简短反馈。 |
| Scope（范围，可选） | 本次只整理反馈，不修改产品。 |
| Acceptance criteria（验收标准） | 记录至少两条观察，每条说明操作、感受和建议。 |

日期按上海时区填写，格式为 `YYYY-MM-DD HH:mm`。再填写未来的 **Accept by（接收期限）**、**Next feedback（下次反馈）** 和 **Delivery deadline（交付期限）**。例如按上海时间选择明天上午接收、明天下午反馈、后天下午交付；**Planned start（计划开始）** 可留空，填写时不能晚于交付期限。

点击 **Submit（提交）** 保存。任务此时为 **Draft（草稿）**，只有创建者能看见。打开任务，在详情面板内向下滚动，点击 **Issue task → Submit（下发任务 → 提交）**。

现在任务应为 **Awaiting acceptance（待接收）**，等待 Test Member。复制当前任务 URL，后面用它打开同一条任务。这里由团队负责人直接下发；成员发起任务时需先[提交创建审批](USER-GUIDE.md#任务从创建到验收的流程)。

## 2. 接收任务并记录进展

通过 **Account → Switch user（账户 → 切换用户）** 改用 `member`，密码与初始化时相同。打开刚才复制的任务 URL，阅读任务要求，再点击 **Accept and start → Submit（接收并开始 → 提交）**。

任务应变为 **In progress（进行中）**。这表示负责人已经同意按任务要求执行，并开始工作。

点击 **Record progress（提交正式进展）**，在当前结果中填写“已体验创建和接收任务”，下一步填写“整理两条反馈并提交”，再设一个未来的 **Next feedback（下次反馈）** 时间，提交表单。

刷新任务，确认进展仍可查看。日常讨论可用 **Add comment（发表评论）**；评论不会替代正式进展或延后反馈期限。

## 3. 提交成果

继续用 `member`，点击 **Submit result（提交成果）**。写下你刚才的两条观察，每条包含操作、感受和建议。练习时也可以填写以下模拟成果：

```text
模拟试用反馈：
1. 接收并开始任务后，状态显示为进行中，能看出负责人已开始处理。建议：保留这个状态提示。
2. 操作按钮在详情面板下方，第一次使用时需要向下滚动才能找到。建议：更明显地提示操作入口。
```

填写未来的 **Review by（验收期限）**。证据链接可选；有相关材料时填 HTTP(S) 链接，练习可留空。提交后，任务应为 **Awaiting review（待验收）**，等待 Test Project Manager。

## 4. 验收成果

切换到 `manager`，打开同一任务。对照“两条观察及其操作、感受和建议”的验收标准阅读成果，再点击 **Accept result → Submit（验收通过 → 提交）**。

任务应变为 **Completed（已完成）**。在 **Submissions（成果提交）** 中查看成果，在 **Activity（动态）** 中查看谁接收、记录进展、提交和验收了任务。

如果成果不满足标准，验收人可以用 **Return result（验收退回）** 写明需要补充的内容和下次反馈时间，负责人补充后重新提交。这段流程见[进阶案例](CASE-CSV-EXPORT.md)。

## 接下来按需要使用

日常登录后，先打开 **Action inbox（待处理事项）**，查看 **Assigned to me（待我处理）**，点击一项进入对应任务。搜索、筛选和其他操作见[使用指南](USER-GUIDE.md)。

需要拆分工作时，可以申请执行清单；需要多人配合时，可以设置父子任务、前置依赖或报告阻塞。这些操作见[进阶案例：CSV 导出项目](CASE-CSV-EXPORT.md)。清单达到 100% 后，任务仍需提交成果并通过验收才会完成。
