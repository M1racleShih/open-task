# OpenTask 使用文档

[English](../en/README.md)

OpenTask 用来创建和分配任务、记录进展、提交和验收成果。你可以在一条任务中查看要求、负责人、当前待办和操作历史。最新已打标签的预发布版为 **0.1.2-alpha**，供单团队本机试用。指南也覆盖之后合并到 `mvp` 的优化，各项变化的版本归属见[更新记录](RELEASE-NOTES.md)。

## 第一次使用

1. **[本地安装与登录](QUICKSTART.md)**：从源码启动应用，使用演示账号进入工作区。
2. **[完成第一条任务](FIRST-TASK.md)**：创建任务，切换到负责人接收并执行，再提交成果给验收人。安装完成后，建议为这段练习预留约 10 分钟。
3. **[查找操作和规则](USER-GUIDE.md)**：日常使用时，按需要查待办、进展、任务关系或账号管理。

想继续练习多人审批、阻塞协作、要求变更和成果退回，可以阅读[进阶案例：CSV 导出项目](CASE-CSV-EXPORT.md)。完整案例约需 45–60 分钟，可以分段完成。

## 试用前了解这些限制

本版适合在本机试用单团队任务流程。提交后的任务对全团队可见，项目成员设置不提供数据隔离。当前没有外部身份登录、文件上传、对外消息或 AI Agent 集成，成果证据以链接保存。

负责人接收任务、清单审批、要求变更确认和成果验收都需要相应人员操作。建议用一个小项目体验这些步骤，再判断它们是否有助于你们明确要求、处理变更和跟进成果。真实团队的流程负担、长期使用体验和持续运行容量仍需试用验证。

日期使用上海时区。切换界面语言会翻译控件，任务正文保持原始输入。更多限制见[版本说明](RELEASE-NOTES.md)。
