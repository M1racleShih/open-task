The application uses **Lucide React 1.43.0**, an open-source icon library: https://lucide.dev/ . Lucide is licensed under ISC; icons derived from Feather retain the MIT notice. Both licenses permit commercial use, modification and redistribution subject to retaining their copyright and permission notices.

The complete upstream license, including the Feather notice and icon list, is retained in `web/public/lucide-LICENSE.txt` and copied by Vite into the application distribution at `/lucide-LICENSE.txt`. Keep this file when distributing a build. No proprietary icon service or purchased icon assets are used.

## Solid task glyph (2026-09-10)

`web/TaskIcon.tsx` contains an original solid clipboard silhouette with cut-out checklist marks, released under the MIT license in `web/public/task-icon-LICENSE.txt`. The license is distributed in the built app. It is used in the Task Tree and inspector heading; remaining Lucide/Feather icons retain their existing notices. This is purpose-drawn geometry, not an outline icon with a fill applied.
