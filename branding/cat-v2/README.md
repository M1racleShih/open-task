# OpenTask 猫主题 Logo

![卡通手绘猫 Logo](opentask-cat-logo.png)

以抱着完成任务卡的小猫为主体：奶油色猫身、蓝色耳朵斑块、深蓝手绘轮廓，配手写风格的 OpenTask 字标。采用卡通手绘风格。

- 文件：`opentask-cat-logo.png`，1254×1254，透明背景 RGBA。
- 生成方式：内置 imagegen 工具；提示词见 [PROMPT.md](PROMPT.md)。
- 文件格式为 PNG 位图。
- [紧凑猫咪图形](opentask-cat-mark.png)由内置 imagegen 基于原图编辑，去除底部字标，用于顶部品牌区、文档网页和 favicon；编辑提示词见 [PROMPT.md](PROMPT.md)。
- 完整 Logo 已接入登录页；网页资源副本位于 `web/public/brand/`，文档构建会把这些文件复制到 HTML 的 `assets/brand/`。
- 几何 Logo 资源位于上级目录。
